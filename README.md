# Social Verse Creator Intelligence Automation

MVP روزانه‌ای با معماری صفرهزینه برای جمع‌آوری خبرهای مهم اقتصاد کریتورها، حذف موارد تکراری، تحلیل و تولید توضیح عملی با فارسی محاوره‌ای و انتشار در Forum Topic تلگرام.

## اصل صفرهزینه

هستهٔ این نسخه از API پولی یا اعتبار آزمایشی استفاده نمی‌کند. فیلتر و ساخت پیام پایه به‌صورت محلی و قانون‌محور انجام می‌شود. Gemini Free Tier فقط یک لایهٔ اختیاری برای بهترشدن ترجمه، خلاصه و آموزش است؛ با نبودن کلید، تمام‌شدن سهمیه یا خطای Gemini، سیستم خودکار به تحلیل محلی برمی‌گردد و متوقف نمی‌شود. اجرای روزانه روی GitHub Actions انجام می‌شود و لازم نیست کامپیوتر شخصی روشن بماند. اجرای محلی فقط مسیر پشتیبان و آزمایش است.

برای اجرای ابری بدون هزینه، Repository باید عمومی باشد و workflow از runner استاندارد `ubuntu-latest` استفاده کند؛ طبق مستندات فعلی GitHub، runnerهای استاندارد در Repositoryهای عمومی رایگان‌اند. Repository خصوصی از سهمیهٔ ماهانه استفاده می‌کند و انتخاب مناسبی برای شرط «بدون هزینه» نیست. سیاست آیندهٔ یک سرویس ثالث قابل تضمین نیست، بنابراین وابستگی اجرایی در GitHub اختصاصی نشده و در صورت تغییر سیاست می‌توان همین برنامه را به یک زمان‌بند رایگان دیگر منتقل کرد.

## جریان کار

`RSS → freshness/duplicate filters → optional Gemini quality layer → local fallback → Telegram → history`

## اجرای محلی امن

نیازمند Python 3.12 است.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
PYTHONPATH=src python -m social_verse.main
```

فایل نمونه به‌صورت پیش‌فرض `DRY_RUN=true` دارد؛ بنابراین هیچ پیام واقعی ارسال نمی‌شود.

## راه‌اندازی GitHub Actions

Repository secrets زیر را تعریف کنید:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID` (شناسهٔ گروه، معمولاً عددی منفی)
- `TELEGRAM_TOPIC_ID` (شناسهٔ thread تاپیک Creator Intelligence؛ برای گروه بدون Forum خالی بگذارید)
- `GEMINI_API_KEY` (اختیاری؛ فقط برای ارتقای کیفیت با Free Tier)

سپس workflow با نام **Creator Intelligence Daily News** را یک‌بار دستی اجرا کنید. اجرای زمان‌بندی‌شده هر روز ساعت 07:00 UTC انجام می‌شود.

برای جلوگیری از هزینه، برای پروژهٔ Gemini حساب Billing یا روش پرداخت فعال نکنید. مدل را می‌توان با Repository variable اختیاری `GEMINI_MODEL` تغییر داد. نبودن Gemini هیچ‌وقت جلوی اجرای بات را نمی‌گیرد.

ربات تلگرام باید عضو گروه باشد و اجازهٔ ارسال پیام در تاپیک مقصد را داشته باشد. همهٔ پیام‌های خودکار با گزینهٔ `disable_notification` بی‌صدا ارسال می‌شوند. Workflow بعد از هر انتشار موفق، `data/published_news.json` را commit می‌کند تا حافظهٔ اجرای بعدی حفظ شود.

## تنظیم منابع

منابع RSS در `config/feeds.json` نگهداری می‌شوند. هر ورودی باید `name`، `category` و `url` داشته باشد. خراب‌شدن یک feed کل اجرا را متوقف نمی‌کند.

## محدودهٔ MVP

- دریافت RSS و محدودکردن خبرها به بازهٔ زمانی اخیر
- حذف تکراری با URL/hash و شباهت عنوان
- ارتقای اختیاری ترجمه، خلاصه و آموزش با Gemini Free Tier
- بازگشت خودکار به تحلیل محلی در صورت خطا، محدودیت یا حذف Gemini
- نوشتن راهکارها به شکل ساده، مستقیم و مرحله‌به‌مرحله، بدون فرض دانش تخصصی
- ارسال مستقیم به Telegram Forum Topic
- ثبت تاریخچه فقط پس از ارسال موفق
- dry-run برای بررسی بدون انتشار

ویژگی‌های Viral Radar، دستیار محتوا و گزارش هفتگی برای فازهای بعدی محفوظ‌اند.
